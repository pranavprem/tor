## Project Overview
Docker container running Firefox browser that routes through a Tor SOCKS proxy. Moved from the UGREEN Docker app to this dedicated repo for better management.

## Key Notes
- Originally part of UGREEN NAS Docker app, now standalone
- Routes browser traffic through Tor SOCKS proxy
- Used for privacy-sensitive browsing
